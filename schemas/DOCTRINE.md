# DOCTRINE — the float/compose loop (slow-clock)

> Read-many, write-rarely. This file states what we hold true about
> ontology work; `challenges/FLOAT_CHALLENGE.md` commissions it,
> `schemas/README.md` governs the catalog. Amend only on the walk,
> deliberately, logged. Filed 2026-09-09 after the session that earned it.

## The world provides; the system records; inference bridges

Corpus, identity, scope — read off the world, never invented. Identity is
`thing × aspect` (`my_file.c:security`), dictated outside, recorded in
`.members.txt`. A design that mints what it could have read is wrong.

## Nothing is buried; everything is shelved with a label

Four altitudes, one rule — pass sideways, never destroy:

- ingestion keeps lossy-but-kept (membrane);
- data keeps drift-but-kept (valid JSON in, conforming output out);
- schemas keep merge-coercible (union + coercion list, always version);
- records keep residuals-but-kept (the shelf below).

## The ambient envelope travels with every artifact

`_scope` (the remit) · `_fit` (self-reported 0..1 coverage of it) ·
`_residuals` (in-scope overflow, verbatim) · `_reasoning` (the sorting
judgment + what would absorb the shelf). Same fields on schemas, records,
merges, disputes, reports — always about *the act that produced the
artifact*. Merge-safe by construction (identical shapes union clean).

## Scope bounds the shelf; the shelf feeds the float

Three-way sort on everything noticed: in-scope and held → a field;
in-scope but unholdable → `_residuals`; out-of-scope → dropped, or routed
as a hunt lead for another subset (inward to deepen, outward to widen).
`_scope` is written at float time; without it the shelf is a junk drawer.

## Trust inference; verify by cross-check

Fit is self-reported — the model felt the strain, arithmetic can't. The
number is a claim; residuals + reasoning are the evidence; discard what's
bad. Every mechanical substitute for judgment is a place learning goes
to die. Computed ratios are residuals-thinking with a calculator.

## Migration is inference, so version freely

Change schemas however you want; the next match run coerces. `ZontaxMergeError`
is a coercion worklist with field paths, not a verdict. Semver is sequence
numbers. The one hard wall is parse validity — nothing coheres against
nonsense. Strictness anywhere else is database-brain in an inference system.

## Structure is a query-time act

Ingestion stays dumb and total. Ontologies, relations, compressions float
above and re-float on fit-decay. Hierarchy is recursive float (parents are
compressed children, each with envelopes); levels are input-scope choices
(file, directory, repo) with priced lossiness; relations are records over
pairs. One brief shape, one envelope, one loop producing all three.

## One ratio instruments the loop

`fit` gates records (below bar → reject to misfit, never destroy);
mean `1 − fit` tracks schema health (loss — publish it per version);
rejection clusters trigger floats (clustered → grow; scattered → ignore;
mature + clustered → the world moved). Same shape at record, schema, and
corpus altitude.

## Judgments need holders

`correct`, taste-gates, dispute resolutions carry *whose* (a Scion).
Unattended judgment manufactures substitute selves. Sessions are
addresses; Scions are continuity — match same-scion, not same-session.

## Cheap inference watches; holders judge; envelopes remember

Single-shot structured inference (float, match, probes) notices, emits,
sleeps. Turn-capable agents wake on surprise with the full briefing
(`corr` journey + envelope) and spend expensive turns only on judgment.
Wake is respawn-with-briefing; dormancy is the resting state, not failure.
